# Contributing to TalkAStranger Stream Overlays

We welcome new OBS/Streamlabs overlay themes, alerts, and integrations!

## How to Contribute
1. Fork the repository.
2. Create your theme branch: `git checkout -b feat/new-theme`.
3. Test your theme locally by opening `overlay.html?theme=yourtheme` in any browser.
4. Open a Pull Request!

## Good First Issues
- Add new animated CSS alert themes (e.g., Cyberpunk Neon, Retro Vaporwave, Minimalist Gold).
- Sound effects configuration for live gift and match events.
- Streamlabs widget integration guides.
